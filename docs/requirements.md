# 速読トレーニングアプリ 要件定義書

**バージョン**: 2.0.0
**最終更新日**: 2026-03-09
**ステータス**: 確定
**アプローチ**: MVP（最小限で価値検証）

---

## 1. プロジェクト概要

### 1.1 目的と背景

小学1〜6年生が家庭や塾で楽しみながら速読力を鍛えられるWebアプリを開発する。文章を速く読むための「目の使い方」と「脳の文字認識・理解力」の2つの軸で速読能力を高める。初期は無料で価値検証を行い、将来的に月額課金モデルへ移行する。

### 1.2 成果目標

| 項目 | 内容 |
|------|------|
| 成果の詳細定義 | 小学1〜6年生が家庭や塾で楽しみながら速読力を鍛えられるWebアプリ。視線移動トレーニングとゲーミフィケーションで継続的な個人学習を実現する |

### 1.3 成功指標

**定量的指標:**
1. 1日あたり平均トレーニング回数3回以上
2. 1ヶ月継続率60%以上
3. トレーニング後の認識クイズ正答率70%以上

**定性的指標:**
1. 子どもが「またやりたい」と思える楽しさ
2. 保護者が子どもの成長を実感できる安心感
3. 小学1年生でも操作に迷わない直感的なUI

### 1.4 ターゲットユーザー

- **小学1〜6年生（主要ユーザー）**: ゲーム感覚で楽しく速読力を身につけたい子ども
- **保護者**: 子どもの学習進捗を確認したい親（将来フェーズ）
- **教育機関**: 将来的な導入を検討する学校・塾（将来フェーズ）

### 1.5 MVPでの割り切り

| 項目 | MVP | 将来版 |
|------|-----|--------|
| 認証 | なし（localStorage） | JWT認証（子ども/保護者ロール） |
| データ保存 | ブラウザlocalStorage | Neon PostgreSQL + Prisma |
| キャラクター収集 | なし | ポイントでアンロック |
| 保護者機能 | なし | ダッシュボード |
| バックエンド | なし | Node.js + Express |
| 課金 | 無料 | 月額課金 |

## 2. システム全体像

### 2.1 MVP機能一覧

| 機能 | 説明 | 必須/任意 |
|------|------|----------|
| 視覚トレーニング | 6種類の視線移動パターンで目の使い方を訓練 | 必須 |

### 2.2 ページ構成（MVP: 2ページ）

| ID | ページ名 | ルート | 主な目的 | 含まれる機能 | 優先度 |
|----|---------|-------|---------|-------------|-------|

| P-002 | 結果・記録ページ | `/records` | スコア表示・過去の記録一覧・簡易グラフ | 履歴一覧、成長グラフ、統計サマリー | 高 |

**ヘッダー:**
- アプリケーションロゴ「速読マスター」
- 現在のレベルとポイント表示
- ページ切り替えナビゲーション（トレーニング / 記録）

## 3. ページ詳細仕様

### 3.1 トレーニングページ (P-001)

**ページ概要**: トレーニングの選択→実行→確認クイズ→結果表示をステップ形式で1ページ内で完結

#### ステップ1: トレーニング選択

**表示要素:**
- 6種類のトレーニングカード（アイコン + 名称 + 簡単な説明）
- 各トレーニングの最高スコア表示
- 難易度（レベル）選択スライダー

**トレーニング種類:**
1. 水平方向視線移動（左右）
2. 垂直方向視線移動（上下）
3. 斜め方向視線移動（X字型）
4. 複合視線移動（垂直＋斜め）
5. 順番追跡（数字順）
6. 連続水平移動

#### ステップ2: トレーニング実行

**表示要素:**
- トレーニンググリッド（記号配置エリア）
- タイマー表示
- 現在のレベル表示

**難易度調整:**
| レベル | 表示間隔 | 説明 |
|--------|---------|------|
| レベル1 | 2秒 | ゆっくり（初心者向け） |
| レベル2 | 1秒 | 普通 |
| レベル3 | 0.5秒 | やや速い |
| レベル4 | 0.25秒 | 速い |
| レベル5 | 0.1秒 | とても速い |
| レベル6 | 同時表示 | 全記号を一度に表示 |

**ゲーム要素:**
- 通常の○に混ざって★や♦が出現
- 色付き記号（赤、青、緑）がランダムに出現
- 出現した特殊記号を記憶しておく必要がある

**アニメーション仕様:**
- 60fps維持（Framer Motion + rAF + `performance.now()`）
- アニメーション対象は`transform`と`opacity`のみ（GPU合成最適化）
- iPad低電力モードのフォールバック対応

#### ステップ3: 確認クイズ

**表示要素:**
- 「トレーニング中に出てきた特殊記号はどれ？」形式の選択問題
- 4択の回答ボタン（大きなタップ領域: 最低44x44px）
- 3〜5問出題

**判定ロジック:**
- 正答1問につき基本10ポイント
- 全問正解ボーナス: +20ポイント
- レベルに応じたポイント倍率（レベル1: x1.0 〜 レベル6: x3.0）

#### ステップ4: 結果表示

**表示要素:**
- 今回のスコア（大きく表示）
- 正答率（%）
- 獲得ポイント
- 前回スコアとの比較（↑↓表示）
- 「もう一度」ボタン / 「記録を見る」ボタン

### 3.2 結果・記録ページ (P-002)

**ページ概要**: 過去のトレーニング記録の一覧表示と成長の可視化

**表示要素:**

1. **統計サマリー（上部）**
   - 累計トレーニング回数
   - 現在のレベル
   - 累計ポイント
   - 平均正答率

2. **成長グラフ（中部）**
   - 過去30日間のスコア推移（折れ線グラフ）
   - トレーニング種類ごとにフィルター可能
   - 正答率の推移

3. **トレーニング履歴（下部）**
   - 日付、トレーニング種類、レベル、スコア、正答率
   - 新しい順に表示
   - 無限スクロールまたはページネーション

## 4. データ設計概要

### 4.1 localStorage データ構造

MVPではlocalStorageにJSON形式で保存する。

**TrainingRecord:**
```typescript
interface TrainingRecord {
  id: string;              // UUID
  type: TrainingType;      // トレーニング種類(1-6)
  level: number;           // 難易度レベル(1-6)
  score: number;           // スコア
  correctRate: number;     // 正答率(0-100)
  earnedPoints: number;    // 獲得ポイント
  quizAnswers: QuizAnswer[]; // クイズ回答詳細
  createdAt: string;       // ISO 8601日時
}
```

**UserProgress:**
```typescript
interface UserProgress {
  totalPoints: number;     // 累計ポイント
  currentLevel: number;    // 現在のレベル
  totalTrainings: number;  // 累計トレーニング回数
  bestScores: Record<TrainingType, number>; // 種類別最高スコア
}
```

**QuizAnswer:**
```typescript
interface QuizAnswer {
  questionIndex: number;
  selectedOption: number;
  correctOption: number;
  isCorrect: boolean;
}
```

**TrainingType:**
```typescript
type TrainingType =
  | 'horizontal'    // 水平方向
  | 'vertical'      // 垂直方向
  | 'diagonal'      // 斜め方向
  | 'complex'       // 複合
  | 'sequence'      // 順番追跡
  | 'continuous';   // 連続水平
```

### 4.2 バリデーション

- score: 0以上の整数
- correctRate: 0〜100の数値
- level: 1〜6の整数
- type: 6種類のTrainingTypeのいずれか
- createdAt: 有効なISO 8601形式

## 5. セキュリティ要件

### 5.1 全プロジェクト必須

- ヘルスチェックエンドポイント: `/api/health`（将来のバックエンド追加時）
- HTTPS強制（本番環境 - Vercelが自動対応）
- 入力値サニタイゼーション（XSS対策）

### 5.2 MVP固有の考慮事項

- localStorageのデータは暗号化不要（個人情報を含まないため）
- localStorage容量上限（5MB）を超えた場合の古いデータ自動削除
- 不正なJSON注入に対するパース時のバリデーション

### 5.3 将来の認証機能追加時

- ブルートフォース対策（5回失敗でロック）
- パスワードポリシー（8文字以上）
- セッション管理、CSRF対策
- 子どもの個人情報保護（COPPA準拠を検討）

## 8. 非機能要件

- **レスポンシブデザイン**: タブレット（iPad）とPCの両方で快適に操作できるUI
- **アニメーション性能**: 記号の表示切り替えが滑らかに動作（60fps維持）
- **タッチ対応**: タッチターゲット最低44x44px（Apple Human Interface Guidelines準拠）
- **データ永続化**: ブラウザを閉じても進捗データがlocalStorageで保持される
- **アクセシビリティ**: `prefers-reduced-motion`設定を尊重しアニメーション簡略化に対応
