## ユーザーゴール

1. トレーニングの累計回数・レベル・ポイント・平均正答率を一目で確認できる
2. 過去30日間のスコア推移をグラフで確認できる
3. トレーニング種類でフィルターして成長傾向を把握できる
4. 過去のトレーニング履歴を一覧で振り返ることができる

---

```yaml
URL: http://localhost:3847/records
```

## テスト項目詳細

### E2E-REC-001: ページアクセス・統計サマリー表示

**前提条件:** なし

**操作手順:**
1. `http://localhost:3847/records` にアクセス

**検証ポイント:**
- 「きろく」の見出しが表示される
- 統計サマリーとして以下の4カードが表示される:
  - 「トレーニング回数」ラベルと「N回」の値
  - 「現在のレベル」ラベルと「Lv.N」の値
  - 「累計ポイント」ラベルと「Npt」の値
  - 「平均正答率」ラベルと値（記録なし時は「---」、あり時は「N%」）

---

### E2E-REC-002: 記録なし状態の表示

**前提条件:** localStorage の `sokudoku-records` キーが空または存在しない

**操作手順:**
1. localStorage から `sokudoku-records` を削除
2. `http://localhost:3847/records` にアクセス

**検証ポイント:**
- スコア推移セクションに「まだデータがないよ。トレーニングしてみよう！」が表示される
- トレーニング履歴セクションに「トレーニングをすると、ここに記録が表示されるよ！」が表示される
- SVGのグラフ要素は表示されない
- テーブル要素は表示されない

---

### E2E-REC-003: 記録あり状態のスコア推移グラフ表示

**前提条件:** localStorage の `sokudoku-records` に複数件のTrainingRecordデータがセットされている

**操作手順:**
1. `http://localhost:3847/records` にアクセス
2. スコア推移セクションを確認

**検証ポイント:**
- 「スコア推移」の見出しが表示される
- 以下のフィルターチップが表示される:
  - すべて（初期状態で選択済み・強調表示）
  - 水平方向
  - 垂直方向
  - 斜め方向
  - 複合
  - 順番追跡
  - 連続水平
- SVG要素が表示され、折れ線（path要素）とデータポイント（circle要素）が描画される

---

### E2E-REC-004: スコア推移のフィルター切替

**前提条件:** E2E-REC-003 完了後（複数種類の記録データあり）

**操作手順:**
1. 「水平方向」チップをクリック
2. グラフの表示を確認
3. 「すべて」チップをクリック
4. グラフの表示を確認

**検証ポイント:**
- 「水平方向」クリック後:
  - 「水平方向」チップが強調表示（背景色がprimary、白文字）に変わる
  - 「すべて」チップが非選択状態になる
  - グラフのデータポイント数が水平方向の記録件数と一致する
- 「すべて」クリック後:
  - 「すべて」チップが強調表示に戻る
  - 「水平方向」チップが非選択状態に戻る
  - グラフのデータポイント数が全記録の件数（最大30件）と一致する

---

### E2E-REC-005: トレーニング履歴テーブル表示

**前提条件:** localStorage の `sokudoku-records` に複数件のTrainingRecordデータがセットされている

**操作手順:**
1. `http://localhost:3847/records` にアクセス
2. トレーニング履歴セクションを確認

**検証ポイント:**
- 「トレーニング履歴」の見出しが表示される
- テーブルヘッダーに「日付」「種類」「Lv」「スコア」「正答率」の5列が表示される
- 先頭行のデータが最新の記録である（新しい順にソート）
- 各行に以下の形式でデータが表示される:
  - 日付: 「M/D」形式
  - 種類: トレーニング種類の日本語ラベル（水平方向・垂直方向など）
  - Lv: 数値
  - スコア: 数値
  - 正答率: 「N%」形式

### E2E-REC-006: 履歴テーブルのページネーション

**前提条件:** localStorage の `sokudoku-records` に11件以上のTrainingRecordデータがセットされている

**操作手順:**
1. `http://localhost:3847/records` にアクセス
2. 履歴テーブルの行数とページネーションを確認
3. 「次へ」ボタンをクリック
4. 「前へ」ボタンをクリック

**検証ポイント:**
- 初期状態:
  - テーブルに10件の行が表示される
  - 「1 / N」のページ表示がある（Nは総ページ数）
  - 「前へ」ボタンがdisabled
  - 「次へ」ボタンがenabled
- 「次へ」クリック後:
  - ページ表示が「2 / N」に更新される
  - テーブルの内容が2ページ目のデータに切り替わる
  - 「前へ」ボタンがenabledになる
- 「前へ」クリック後:
  - ページ表示が「1 / N」に戻る
  - テーブルの内容が1ページ目のデータに戻る
  - 「前へ」ボタンが再びdisabledになる

---

### E2E-REC-007: トレーニング実行後の記録反映

**前提条件:** localStorage をクリアした初期状態

**操作手順:**
1. `http://localhost:3847/` にアクセス
2. トレーニングを選択して実行し、クイズに回答して完了する
3. 結果画面の「記録を見る」ボタンをクリック

**検証ポイント:**
- URLが `/records` に遷移する
- 統計サマリーの「トレーニング回数」が「1回」と表示される
- 統計サマリーの「累計ポイント」が0ptより大きい値で表示される
- 統計サマリーの「平均正答率」が「---」ではなく「N%」形式で表示される
- トレーニング履歴テーブルに1行のデータが表示される
- 表示された記録の種類が、実行したトレーニング種類と一致する
